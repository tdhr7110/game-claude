# CHIMERA BUTCHER：TEST11 自由合体レイヤー表示テスト

この変更は **TEST11** として実装してください。

対象ブランチは `test11/chimera-free-layer` です。すでに最新の `test10/chimera-integrated-next` を起点として作成済みなので、このブランチ上で実装を続行してください。別のTEST11ブランチは作らないでください。TEST10、main、本番ブランチには直接コミット・マージ・上書きをしないでください。

TEST11では、同一部位の複数装着に対応したプレイヤー画像の自由合体表示テストを実装してください。

## 目的

同じ腕を1～6本装着した場合でも、画像が完全に重ならず扇状に表示されるかを検証します。今回は見た目の検証が目的で、戦闘ロジック・能力計算・部位効果・セーブ形式は変更しません。

## 素材

素材はすでに `public/assets/chimera-layers/` に配置済みです。移動・複製せず、このパスから使用してください。

- `00-base-core.png`：素体
- `01～15-*.png`：合体用レイヤー
- `layer-manifest.json`：部位画像と接続点
- `anchor-layouts.json`：カテゴリ別の配置候補

全画像は256×256pxの透過PNGです。GitHub Pagesのサブパスでも動く相対パスを使用してください。

## レンダリング仕様

1. 256×256の相対配置コンテナを作る
2. 素体画像を中央へ表示する
3. 装着部位をカテゴリ別にグループ化する
4. `anchor-layouts.json` の先頭から装着数分の接続点を割り当てる
5. `layer-manifest.json` のpivotが接続点に一致するよう配置する
6. rotation・mirror・scale・zを適用する
7. 画像は `position: absolute`、コンテナは `position: relative` とする
8. ドット絵がぼやけないよう `image-rendering: pixelated` を指定する

表示座標の基本式：

```js
left = anchor.x - pivot.x * scale;
top  = anchor.y - pivot.y * scale;
```

変形はpivotを基準に行ってください。実装方式はCSS TransformまたはCanvasのどちらでも構いませんが、既存構成に合う低コストな方を選んでください。

## 重複表示ルール

- 腕：最大6本を扇状表示
- 翼：最大4枚
- 角：最大5本
- 尻尾：最大3本
- 脚：最大4本
- 内臓：最大3個。超過分は代表表示
- 表示上限を超えた分は、キャラクター右上に `×N` の小さなバッジを表示する
- ゲーム内部の装着数・能力値は制限しない

同じ画像を複数回使用し、左右側はmirror、各接続点ではrotationとzを変えてください。装着順に依存して表示が毎回変わらないよう、部位IDと取得順で安定ソートしてください。

## テストモード

既存の開発者モード／テストモード内だけに、次の確認UIを追加してください。

- 腕：0～8本
- 翼：0～6枚
- 角：0～7本
- 尻尾：0～5本
- 脚：0～6本
- 部位種類を切り替えるプルダウン
- 自動配置のON/OFF
- 接続点・pivotを確認するデバッグ表示のON/OFF

本番通常プレイではテストUIと接続点を表示しないでください。

## 制約

- 戦闘、能力、敵、ドロップ、コマンド、進化、セーブ形式を変更しない
- 新しい外部ライブラリを追加しない
- Base64で画像を埋め込まない
- 無関係なリファクタリングをしない
- 既存の縦画面UIを崩さない
- 表示領域は `clamp(128px, 42vw, 190px)` 程度に収める
- 画像読み込み失敗時は既存の絵文字表示へフォールバックする
- 同じ部位を複数表示するときはPNGを褉製保存せず、同一画像URLを再利用する
- リポジトリへ配置した実装用素材は約0.68MB。不要な再圧縮・Base64化・重複コピーで容量を増やさない

## 受け入れ条件

1. 素体だけを表示できる
2. 同じ腕を1～6本に増やしても完全には重ならない
3. 左右反転と角度変更が適用される
4. 前側と後ろ側の部位が正しいz順で表示される
5. 7本以上の腕は6本表示＋超過バッジになる
6. 翼・角・尻尾・脚でも個数別配置が動く
7. スマホ縦画面からはみ出さない
8. 既存ゲームロジックに影響しない
9. ビルド・既存テストが通る
10. GitHub Pagesのサブパス配信でも画像が表示される
